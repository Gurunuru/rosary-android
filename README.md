# 묵주기도 앱 (안드로이드)

기도 화면 전체는 `app/src/main/assets/index.html` 한 파일에 들어 있습니다.
안드로이드 앱은 이 파일을 WebView로 띄우고, 진동과 화면 켜두기를 휴대폰 기능에 연결합니다.

## Google Play 출시용 파일 만들기 (GitHub 자동 빌드)

1. `gradle.properties`의 `APP_ID`를 본인만의 앱 ID로 바꿉니다. (예: com.maria.rosary, Play에 올린 뒤에는 변경 불가)
2. GitHub 비공개 저장소에 이 폴더의 내용 전체를 올립니다. 숨김 폴더 `.github`도 포함하고, `.jks` 키 파일은 올리지 마세요.
3. 저장소 Settings › Secrets and variables › Actions 에 업로드 키 Secrets 4개를 등록합니다.
   (KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD — 값은 rosary-signing-key.zip 안내 파일 참고)
4. Actions 탭 › Build Android app › Run workflow. 끝나면 Artifacts에서 내려받습니다.
   - rosary-play-store-aab : Play Console에 올리는 파일 (app-release.aab)
   - rosary-release-apk    : 출시용과 같은 앱을 휴대폰에 직접 설치해 보는 용도
   - rosary-test-apk       : 테스트용 (Secrets 없이도 생성)
5. 버전 번호는 빌드할 때마다 자동으로 올라갑니다.

Android Studio로 열어서 Build › Build APK(s)로 테스트용 APK를 만들 수도 있습니다.

## 기술 사양

- 대상 Android 16 (API 36), 최소 Android 8.0 (API 26)
- 인터넷 권한 없음, 진동 권한만 사용. 제목용 명조 글꼴은 앱 안에 포함 (fonts/, SIL OFL 라이선스)
- 화면 끝까지 그리기(edge-to-edge) 대응: 상태바·내비게이션바 뒤 색은 화면별로 앱이 칠함
- 뒤로가기: Android 13+ OnBackInvokedCallback, 그 이하 onBackPressed

## 들어 있는 기능

- 시작 화면, 오늘 요일에 맞는 신비 자동 선택 + 그날만 직접 고르기
- 설정 › 요일별 신비: 요일마다 바칠 신비를 직접 지정 (기본값으로 되돌리기 가능), 이어서 기도하기(진행 위치 자동 저장)
- 시작 순서: 성호경 → 1단 묵상 → 사도신경 → 주님의 기도 → 성모송 3번 → 영광송 → 구원의 기도 → 1단(주님의 기도부터) …
- 기도문 숨기기: 숨기면 묵주가 돌아가며 구슬이 넘어가는 화면으로 전환 (화면 탭 = 다음, 옆으로 밀기 = 다음/이전)
- 묵주 스킨 5종(금빛·진주·원목·장미·청금석)과 구슬 넘김 효과 5종(없음·은은한 빛·빛 물결·반짝임·후광) — 프로필 화면에서 선택
- 도전과제 7종: 앱을 쓰면서 달성하면 스킨·효과가 열리고 자동 적용 (처음엔 금빛 스킨 + 은은한 빛만 사용 가능)
  눈을 감고 기도(빛 물결) · 세 송이 꽃다발(진주) · 빛의 길(반짝임) · 아침을 여는 기도(원목) · 닷새의 기도(장미) · 천 번의 성모송(후광) · 보름의 기도(청금석)
- 앱 사용법: 시작 화면 왼쪽 위 '사용법' (기능 안내 7가지 + 묵주기도 바치는 순서)
- 묵주 고리에 현재 구슬 표시, 단·구슬 진행 표시, 기도문 전문
- 기도 기록 달력: 완료한 날(금색), 중단한 날(갈색 테두리), 오늘 진행 중(점선), 이달 통계와 연속 완료 일수
- 내 프로필: 세례명/이름, 프로필 사진(일러스트 8종 또는 휴대폰 사진), 테두리, 통계
- 리워드 12종: 1~10번 일반 리워드(연속·누적·신비·성월), 11·12번 최상위 리워드(한 달 40회·60회 완료) → 특별 사진·테두리 해금
  최상위 기준 횟수는 index.html의 `TOP_MONTH_1`, `TOP_MONTH_2` 값으로 바꿀 수 있습니다.
- 설정: 진동, 단 시작 종소리, 구슬 넘김 소리, 기도 중 화면 켜두기, 글자 크기
- 휴대폰 뒤로가기: 설정 창 닫기 → 시작 화면 → 앱 종료

## 스킨·효과 추가하는 법

`index.html`에서 `var SKINS = {` 를 찾아 한 줄을 추가하면 새 스킨이 생깁니다.
각 값의 의미: up-mini(위쪽 작은 묵주의 남은 구슬), up(남은 작은 구슬), up-big(남은 큰 구슬·메달), done(바친 구슬),
thread(묵주 줄), cur(지금 구슬), glow(빛 색, "R,G,B"), cross(남은 십자가), sheen(구슬 광택, 없으면 none).
그 다음 `SKIN_ORDER` 목록에 새 이름을 넣으면 프로필 화면에 나타납니다.
새 스킨·효과를 도전과제로 얻게 하려면 `var CHALLENGES = [` 목록에 한 줄을 추가하고 `gives: { skin: '이름' }` 또는 `gives: { fx: '이름' }`을 지정하세요.
도전과제 없이 처음부터 쓰게 하려면 `FREE_SKIN`, `FREE_FX` 목록에 넣으면 됩니다.
넘김 효과는 `EFFECTS` 목록과 `playFx` 함수, CSS의 `.fx-` 애니메이션으로 이루어져 있습니다.
